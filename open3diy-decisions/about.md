# Decisiones open3diy: un camino compartido

Este repositorio sigue la filosofía de "aprender haciendo" y promueve compartir el conocimiento adquirido durante el proceso.

Aquí se documentan y analizan las decisiones de diseño tomadas en open3diy, abarcando el sitio web, la DAO y la Dapp. El objetivo de Open3DIY es crear un espacio común para la financiación y el desarrollo de soluciones tecnológicas en un entorno abierto y colaborativo.

La mejor forma de comprender open3diy es a través de una documentación clara y didáctica, que permita a cualquiera aprender, tanto de los aciertos como de los errores del proyecto. Así, cualquier interesado podrá consultar este sitio y entender cómo se decidieron, diseñaron y construyeron cada una de las partes, independientemente del resultado final.

Este espacio, además, tiene un claro enfoque educativo. Por lo tanto, también sirve para compartir el conocimiento y la experiencia adquiridos durante el desarrollo del proyecto.
