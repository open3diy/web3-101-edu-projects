# Reescribir texto seleccionado

Usa este prompt sobre una selección activa del editor.

Reescribe directamente en el archivo únicamente el texto seleccionado.

Vuelve a escribirlo desde cero para que se entienda mejor. Usa un lenguaje más claro, menos técnico y más educativo. Si hace falta, cambia el orden de las ideas, divide frases largas o reorganiza el párrafo completo.

No hagas retoques mínimos ni cambios cosméticos. Prioriza que el contenido se entienda de verdad.

No expliques nada fuera del documento. No añadas notas, comentarios ni prefacios. No cambies nada fuera de la selección.

Pon siempre enlace de referencia cuando se mencione cualquier ejemplo concreto: un protocolo, servicio, DApp, estándar o rol específico. Por ejemplo, ERC-20 como estándar, Uniswap como DApp, o "liquidador" como rol con comportamiento propio dentro de un protocolo.

Si aparece por primera vez un concepto, definición, rol o mecanismo relevante en todo el documento, pon un enlace de referencia explicativo. Por ejemplo, si se habla por primera vez de lo que es una pool de liquidez, o de cómo funciona una liquidación, pon un enlace a esa definición. No lo hagas si ese concepto ya está enlazado anteriormente en el documento; e igualmente, si ese concepto se desarrolla en el propio documento, no pongas un enlace externo, pon un enlace al marcador de la sección correspondiente.

Esta regla de enlaces se aplica también a lo que tú mismo añadas al reescribir. Si introduces un concepto, protocolo, ejemplo o mecanismo que no estaba en el texto original pero que añades para clarificar, ese nuevo elemento también necesita enlace, exactamente igual que si ya hubiera estado en el texto original.

Cuando termines, detente y espera la siguiente selección.
